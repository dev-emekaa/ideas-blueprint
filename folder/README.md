# Ideas Blueprint

A founder's kit for picking a product worth building and shaping it into a Product Brief, a PRD and a logo. The PRD is ready to hand to a build pipeline such as Backend Blueprint.

---

## What's inside

| File | What it is | Where to use it |
| --- | --- | --- |
| `1-finding-ideas.md` | Guide: where to find ideas that already make money, how to check the evidence, and the scorecard for picking one. Ends with the idea research prompt, which finds or evaluates ideas and runs every check for you | Read the guide. Run the prompt in Claude with a browser you're signed into, or any AI with web search |
| `2-product-brief-and-prd.md` | Two prompts: rough idea → validated concept → Product Brief → PRD | Any AI chat with web search turned on |
| `3-logo-prompt.md` | Prompt: a logo system and the icon files every platform needs | An AI that generates images, such as ChatGPT or Gemini |

---

## How to use it

1. **Find and check ideas** with the idea research prompt, or by hand with the guide's sources and scorecard. Drop any idea that fails a must-pass check.
2. **Write the Product Brief and PRD** with Prompt 1. The concept summary gives a verdict first, so you can still stop before writing anything.
3. **Design the logo** from the approved brief.
4. **Build.** Put the brief and PRD in your project's `docs/product-docs/`. With Backend Blueprint, run `/feature-areas` next. Features for later phases are planned inside the project with Backend Blueprint's `/feature-requirements`, which reads the project's documents first.
